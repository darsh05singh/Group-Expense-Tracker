# Group-Expense-Tracker
A program that allows users to keep track of expenses and splits while traveling with a group.

## The Problem

The problem I want to solve is managing and splitting expenses when traveling as a group. Often times it is hard to keep track of who paid for what while on a trip with many people, which can lead to overspending beyond your set budget.

## The MVP


The MVP will be a Java command line program where users can create groups, and within create trips or access current existing ones. In there, they will have the ability to add expenses and specify among whom the expenses were shared. The program would then output how much each person owes and to whom they owe, as well as give a trip summary at the end of each trip.


## Future

The future version would be able to add custom splits(right now its equal split), edit past expenses and payments, modify group sizes in the middle of the trip, and have a personal and group budget tracking update after each expense.


## Tech Stack

- **Language:**  Java
- **Libraries:** Java's Library: Scanner/IO, Serializable, and LocalDate
